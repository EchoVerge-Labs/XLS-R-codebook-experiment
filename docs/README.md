## Reading the numbers

Every figure in these pages is generated by [`scripts/make_figures.py`](scripts/make_figures.py)
from result files tracked in the repository, and every table gives the file it was read
from. Nothing is transcribed by hand.

Two labels recur throughout:

- **Pre-registered**: the design, comparison and decision criteria were committed before
  any result existed. The configuration files named in each page hold them.
- **Post-hoc**: added afterwards, usually in response to review. These results are
  reported, but they carry less evidential weight and are always labelled.

[`PAPER.html`](../PAPER.html) is a full technical report of the three pre-registered
experiments. It predates the post-hoc analyses, which are documented only here.
